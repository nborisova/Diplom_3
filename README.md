## Дипломный проект. Задание 3: Тестирование веб-приложения

### Автотесты для проверки интерфейса сервиса Stellar Burgers

### Реализованные сценарии

Созданы тесты для проверки следующих блоков:
- Восстановление пароля
- Личный кабинет 
- Основной функционал
- Раздел «Лента заказов»

### Структура проекта

- `Diplom_3` - пакет, содержащий код программы
- `pages` - пакет, содержащий классы Page Object для блоков
- `tests` - пакет, содержащий тесты для каждого блока

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание allure-отчета**

>  `$ pytest`
>  `$ allure serve allure_results`
